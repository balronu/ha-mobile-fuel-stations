# v0.8.4-beta.1 visual acceptance

The Chromium fixture uses the same five mocked stations for all modes at 390
CSS pixels and desktop width. It verifies order, labels, navigation, no
duplicate station IDs, and the absence of provider calls.

| Mode | Width | Card height | Notes |
| --- | ---: | ---: | --- |
| Detailed | 390px | **477px** / 68px rows | Full station fields, one list |
| Compact | 390px | **444px** / 65px rows | v0.8.3 dense-row regression |
| Individual list | 390px | **452px** / 68px rows | Card-local sorting and fields |
| Individual highlights + list | 390px | **435px** / 119px tiles + 68px rows | Two distinct priority tiles, remainder list |
| Individual no-header | 390px | **423px** / 68px rows | No empty header container |
| Individual full-header | 1200px | **542px** / 86px rows | All optional header fields enabled |

The detailed candidate is 90px shorter than the v0.8.3 reference fixture
(567px), while compact remains exactly at the v0.8.3 reference height (444px).

Screenshots are generated from the offline fixture and are not evidence of a
live Home Assistant dashboard or live provider response.
