# v0.8.3 visual acceptance

The same five offline fixture stations were rendered with Chromium at a 390 CSS
pixel viewport and on a desktop viewport. No Home Assistant, provider, OAuth, or
network data was used.

| Viewport / mode | Card height | Station rows | Row heights | Order |
| --- | ---: | ---: | --- | --- |
| 390px compact | 444px | 5 | 65px each | Shell (nearest), Aral (cheapest Diesel), JET, OMV, no-current-price station |
| 390px detailed | 567px | 5 | 86px each | Shell (nearest), Aral (cheapest Diesel), JET, OMV, no-current-price station |

The detailed view contains one complete list and no separate highlight cards.
The compact view keeps the dense rows and inline marker/navigation slots. The
fixture was also rendered in dark mode to verify that text, dividers, labels and
navigation remain legible.
