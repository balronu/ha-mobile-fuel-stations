# v0.8.4-beta.3 Editor- und Visual-Audit

| Bereich / Option | Ergebnis | Nachweis / Korrektur |
| --- | --- | --- |
| Darstellungsmodus | Funktioniert | Ausführlich, Kompakt und Individuell rendern getrennt |
| Individuelles Layout | Funktioniert | Liste, konfigurierte Liste und Kacheln + Liste getestet |
| Sortierung / Preis-Kraftstoff | Funktioniert | Gemeinsame Priorisierungsfunktion unverändert verwendet |
| Sichtbare Anzahl | Funktioniert | `visible_station_count` begrenzt die gemeinsame Liste |
| Kopfbereich einzeln | Funktioniert | Inhalt und reservierter Container verschwinden gemeinsam |
| Kopfbereich vollständig aus | Funktioniert | Kein `.header`, `.controls` oder `.diagnostics` ohne Auswahl |
| Markenlogos | Behoben | `no-logo` entfernt Logo-Grid-Spalte und Logo-DOM |
| Name vollständig / Ellipsis | Funktioniert | `.name.short`, `title` und responsive Umbrüche geprüft |
| Adresse / Status / Provider | Funktioniert | Gemeinsame Detail-/Metazeilen, fehlende Werte bleiben leer |
| Entfernung | Behoben | Individuell genau einmal in `.detail-meta`; globaler Toggle geprüft |
| Preise / Kraftstofflabels | Behoben | Leere Preiscontainer/Labels werden nicht gerendert |
| Navigation / Anbieter | Behoben | Eine Editoroption; `no-navigation` entfernt leere Spalten |
| Nächste/Günstigste | Funktioniert | Identische Station bleibt einmalig mit beiden Labels |
| Trennlinien | Behoben | Selektor korrigiert: `.no-dividers .station`; Tiles behalten Rahmen |
| Zeilenabstand | Funktioniert | Normal ca. 769px, kompakt ca. 611px bei identischen Mocks |
| Live-Vorschau / Speicherung | Funktioniert | Editor-Events und Wiederherstellung durch `setConfig` getestet |
| Legacy YAML/Storage | Funktioniert | Keine Schlüssel entfernt; Defaults/Fallbacks erhalten |
| Cache-Versionierung | Funktioniert | Bundle marker und URL `?v=0.8.4-beta.3` synchron |

## Responsive Messpunkte

- 390px: Kacheln nebeneinander, ca. 191px je Kachel.
- 359px und 320px: Kacheln kontrolliert untereinander, ohne horizontalen
  Überlauf im Karteninhalt.
- 480px und 768px: Desktop-Grid bleibt zweispaltig.
- Light- und Dark-Mode wurden mit derselben Fixture gerendert.

Screenshots liegen unter
[`docs/releases/assets/v0.8.4-beta.3`](assets/v0.8.4-beta.3/).

Die Prüfung war vollständig isoliert. Es wurden keine produktiven HA-Zustände,
Dashboards, Config Entries, Provider, OAuth-Zugänge oder Backups verwendet.
