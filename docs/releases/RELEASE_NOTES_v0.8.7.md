# Mobile Fuel Stations v0.8.7 Stable

## Deutsch

`v0.8.7` ist ein Wartungsrelease ohne Änderungen an Providerlogik,
Datenmodellen, Entity-IDs, Config Entries oder bestehenden Home-Assistant-
Konfigurationen.

- Öffentliche Versionsangaben und die Lovelace-Cache-Version nennen Stable
  `v0.8.7`.
- Der HACS-Marketplace-Validierungslauf ist als GitHub-CI-Gate enthalten.
- `v0.8.6` bleibt als unmittelbare Stable-Rollback-Version verfügbar.

Es sind keine manuellen Migrationsschritte erforderlich. Produktive Home-
Assistant-Installationen werden durch diesen Release nicht verändert.

## English

`v0.8.7` is a maintenance release with no changes to provider logic, data
models, entity IDs, Config Entries, or existing Home Assistant configuration.

- Public version references and the Lovelace cache version identify Stable
  `v0.8.7`.
- HACS Marketplace validation is included as a GitHub CI gate.
- `v0.8.6` remains available as the immediate Stable rollback.

No manual migration is required. This release does not modify productive Home
Assistant installations.
