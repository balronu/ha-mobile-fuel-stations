# Changelog

## 0.1.0 (beta test branch) - 2026-11-04
- Initial read-only Tessera highlights tile prototype for Home Assistant Mobile Fuel Stations.
- Nearest and cheapest station names, prices, distance, stale-state indicator.
- German and English translations.
- Separate nearest/cheapest sections with larger value text and responsive tile layout.
- Fixed orphan colon before station names and hidden empty headings.
- Passed official Tessera manifest validation and strict Guition firmware preview (light/dark, populated/empty).
- Available for test installation by linking directly to the plugin folder on the development branch; not yet a GitHub Release.
