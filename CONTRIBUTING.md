# Contributing

Issues and pull requests are welcome. Do not include API keys, exact private
coordinates, or private Home Assistant logs in issues, tests, or pull requests.

Run the test suite with `pytest -q` and keep the integration compatible with
the Home Assistant version declared by the project.

When user-facing documentation changes, keep `README.md` and `README.de.md`
in sync. No translation framework is required; update both documents directly.
